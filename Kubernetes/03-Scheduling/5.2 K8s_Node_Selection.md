### 🔍 YAML Breakdown

```yaml
apiVersion: v1
kind: Pod
meta
  name: nnappone
  namespace: learning
  labels:
    app: nnappone
spec:
  containers:
    - name: crackone-app
      image: nginx
      resources:
        requests:
          memory: "300Mi"
        limits:
          memory: "500Mi"
  nodeSelector:
    sku: small   # ← Only run on nodes with label: sku=small

```

> 🔑 Key Field: spec.nodeSelector: { sku: small }
> 
> 
> → Scheduler will **only consider nodes** that have the label `sku=small`.
> 

---

### 📌 How `nodeSelector` Works

| Step | What Happens |
| --- | --- |
| **1. You label nodes** | `kubectl label node <name> sku=small` |
| **2. You deploy Pod** | With `nodeSelector: { sku: small }` |
| **3. Scheduler filters nodes** | Only nodes with `sku=small` are candidates |
| **4. Scheduler scores & picks** | Best node (based on resources, etc.) |
| **5. Pod runs** | On a matching node — **no hardcoding!** |

> ✅ Advantages over nodeName:
> 
> - **Portable**: Works on any cluster with labeled nodes
> - **Resilient**: If node fails, Pod reschedules to **another `sku=small` node**
> - **Scalable**: Add more `sku=small` nodes → scheduler uses them automatically

### 🧪 Lab: Use `nodeSelector` to Target Labeled Nodes

> 💡 We’ll use Minikube or Kind — just label one of your existing nodes.
> 

### 🔧 Step 1: Check & Label a Node

```bash
# 1. See current nodes
kubectl get nodes

# Example output:
# NAME       STATUS   ROLES           AGE   VERSION
# minikube   Ready    control-plane   10m   v1.28.0

# 2. Label your node as "small"
kubectl label node minikube sku=small

# 3. Verify label
kubectl get nodes --show-labels | grep sku
# Should show: minikube ... sku=small

```

### 🔧 Step 2: Deploy the Pod

```bash
# 1. Create namespace
kubectl create namespace learning

# 2. Apply Pod
kubectl apply -f pod-for-specific-node-selector.yml

# 3. Check where it runs
kubectl get pods -n learning -o wide

# ✅ Expected:
# NAME       READY   STATUS    NODE       ...
# nnappone   1/1     Running   minikube   ...

# 4. Describe Pod → confirm nodeSelector
kubectl describe pod nnappone -n learning | grep -A 2 "Node-Selectors"
# Output:
# Node-Selectors:  sku=small

```

### 🔧 Step 3: Clean Up

```bash
# Delete Pod
kubectl delete pod nnappone -n learning

# Remove label (optional)
kubectl label node minikube sku-

# Delete namespace
kubectl delete namespace learning

```

---

### ❓ What If No Node Has the Label?

If **no node** has `sku=small`:

```bash
kubectl get pods -n learning
# NAME       READY   STATUS    RESTARTS   AGE
# nnappone   0/1     Pending   0          30s

kubectl describe pod nnappone -n learning
# Events:
#   Warning  FailedScheduling  5s  default-scheduler  0/1 nodes are available: 1 node(s) didn't match Pod's node affinity/selector.

```

> 🔍 Key Message:
> 
> 
> `"didn't match Pod's node affinity/selector"` → **no node has required label**.
> 

---

### 🆚 `nodeName` vs `nodeSelector`

| Feature | `nodeName` | `nodeSelector` |
| --- | --- | --- |
| **Scheduler used?** | ❌ No | ✅ Yes |
| **Resource checks?** | ❌ No | ✅ Yes |
| **Resilient to node failure?** | ❌ No | ✅ Yes |
| **Works with cluster autoscaler?** | ❌ No | ✅ Yes |
| **Production use?** | ❌ Avoid | ✅ Recommended |

> 🎯 Best Practice:
> 
> 
> Always prefer `nodeSelector` (or better: `nodeAffinity`) over `nodeName`.
>

### 💡 Real-World Use Cases for `nodeSelector`

| Label | Use Case |
| --- | --- |
| `disktype: ssd` | Run databases on fast storage |
| `zone: us-east-1a` | Place Pods in specific AZ |
| `instance-type: gpu` | Run ML workloads on GPU nodes |
| `environment: prod` | Isolate production workloads |

> 🛠️ Pro Tip: Use standardized labels like:
> 
> - `topology.kubernetes.io/zone`
> - `kubernetes.io/os`
> - `node.kubernetes.io/instance-type`

### ➡️ Summary

✅ `nodeSelector` schedules Pods on **nodes with matching labels**.

✅ Uses **scheduler** → checks resources, taints, capacity.

✅ **Resilient & portable** — ideal for production.

🔍 Verify with: `kubectl describe pod` → **"Node-Selectors"** field.

🛠️ Always **label nodes first**: `kubectl label node <name> key=value`.
